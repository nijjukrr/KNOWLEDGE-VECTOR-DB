# Knowledge Vector DB

Knowledge Vector DB is a polished Retrieval-Augmented Generation system for university knowledge management. It lets departments upload institutional documents, builds a searchable local repository, retrieves relevant context across multiple sources, and answers questions with clear source references.

## Features

- Upload `.txt`, `.md`, `.csv`, `.json`, and `.pdf` files.
- Update the repository by uploading newer versions of documents.
- Remove outdated documents from the repository.
- Rebuild the index from stored documents.
- Chunk and index institutional documents locally.
- Search multiple uploaded sources with TF-IDF style scoring.
- Answer user questions using only retrieved context.
- Show source document names, chunk numbers, confidence labels, and relevance scores.
- Run without external APIs or paid services.

## Quick Start

```powershell
python app.py
```

Then open:

```text
http://127.0.0.1:8000
```

## API

| Method | Endpoint | Purpose |
| --- | --- | --- |
| `GET` | `/api/health` | Service health check |
| `GET` | `/api/stats` | Repository metrics and document list |
| `POST` | `/api/upload` | Upload and index a document |
| `POST` | `/api/ask` | Ask a question using retrieved context |
| `POST` | `/api/rebuild` | Rebuild the repository index |
| `DELETE` | `/api/documents/{filename}` | Remove a document |

## Project Structure

```text
app.py              # Web server and routes
rag_engine.py       # Document parsing, indexing, retrieval, and answer generation
templates/index.html
static/styles.css
sample_documents/   # Example university documents for demos
data/documents/     # Uploaded files
data/index.json     # Search index generated by the app
tests/test_rag_engine.py
```

## Notes

PDF support uses Python's standard-library-friendly text extraction fallback. Text-based PDFs may work, but scanned PDFs need OCR, which is outside this dependency-free mini project.
